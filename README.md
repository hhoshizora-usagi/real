# real
Realize（https://enzineroom.jp/realize/）の基本形をベースに、これまで話してきた「工夫」を全部盛り込んだサンプルです。

## 入っている工夫
1. **ヒーロースライダー** … 3枚の写真を交互に切替（ズーム・マスク混在）
2. **キャッチコピーのタイピング表示** … 「エネルギーを、事業の力へ。」を一文字ずつ
3. **ヘッダーのホバー６種** … underline / fill / glow / expand / lift / reveal（画面右下のパネルで切替）
4. **スクロールカウントアップ** … 137 kWh / 2.7 MWh が 0 から
5. **スクロールリビール** … 各セクションが下からふわっと
6. **フルブリード写真＋ケンバーンズ** … 事業・太陽光セクションの写真がゆっくり寄る
7. **テーマ切替** … ダーク（基本形）／ライト
8. **フッターCTA** … ホバーで広がるボタン

## 使い方
`index.html` をブラウザで開くと確認できます。画面右下のパネルで「ホバーの種類」「テーマ」を切り替えて比べられます。

## メモ
- 文章・写真の URL は元の Realize サイト（https://enzineroom.jp/realize/）から参照しています。
- サンプル用なので検索には出ないようにしてあります（noindex）。
